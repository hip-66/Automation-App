הנחיות לשימוש בתיקיית כרום-דרייבר (Chromedriver Directory Instructions):

בתיקייה זו תוכל לשים גרסאות שונות של chromedriver.exe בהתאם לגרסאות הדפדפן שלך.
המערכת סורקת את התיקייה הזו ומציגה את הגרסאות השונות בממשק ה-UI לבחירה.

ניתן לארגן את הקבצים בשתי דרכים:
1. קובץ בודד עם שם גרסה ישירות בתיקייה זו, לדוגמה:
   Chromedrivers/chromedriver_114.exe
   Chromedrivers/chromedriver_120.exe
   Chromedrivers/chromedriver_125.exe

2. תיקייה לכל גרסה ובתוכה הקובץ chromedriver.exe, לדוגמה:
   Chromedrivers/114.0.5735.90/chromedriver.exe
   Chromedrivers/120.0.6099.109/chromedriver.exe
   Chromedrivers/125.0.6422.78/chromedriver.exe

גרסה ברירת המחדל (Default) שהייתה מותקנת בתיקיית Scripts הועתקה לכאן תחת:
Chromedrivers/Default/chromedriver.exe
